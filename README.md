# Fake News Detection System

live link = https://fake-news-detector-csjjjj9vyulaama4pdhgn2.streamlit.app/

A machine learning-based web application for detecting fake news articles using NLP techniques and supervised learning.

## 🚀 Features
- Binary classification of news articles (Fake / Real)
- TF-IDF vectorization of text
- Logistic Regression classifier
- Confidence score display
- Real-time predictions via Streamlit UI

## 🧠 Model Pipeline
1. Text preprocessing and cleaning
2. TF-IDF feature extraction
3. Logistic Regression training
4. Model evaluation using F1-score
5. Real-time inference through web app

## 🛠 Tech Stack
- Python
- Scikit-learn
- NLP
- Streamlit

## 📊 Dataset
- 20,000+ labeled news articles
- Balanced fake vs real samples

## 📈 Performance
- F1 Score: **92%**
- Fast inference suitable for real-time usage

## ⚠️ Limitations
- Limited generalization to unseen news domains
- Cannot verify factual accuracy, only linguistic patterns
- Sensitive to adversarial writing styles
